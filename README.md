# Todo-App

Uma simples aplicação de lista de tarefas com as seguintes funcionalidades:

-   Adicionar novas tarefas.
-   Marcar tarefas como completas.
-   Editar tarefas existentes.
-   Excluir tarefas.
-   Alternância entre temas claro e escuro.
-   Exibição da data e hora atual.

## Como usar

1.  Abra o arquivo `index.html` no seu navegador.
2.  Digite uma nova tarefa no campo de texto e clique em "Add Task".
3.  Marque uma tarefa como completa clicando no checkbox ao lado dela.
4.  Edite uma tarefa clicando no ícone de lápis.
5.  Exclua uma tarefa clicando no ícone de lixeira.
6.  Alterne entre os temas claro e escuro clicando no ícone de lua/sol no cabeçalho.
