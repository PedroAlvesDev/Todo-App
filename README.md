# Todo-App

## Funcionalidades

* **Adicionar Tarefas:** Insira novas tarefas na caixa de texto e clique em "Add Task".
* **Editar Tarefas:** Clique no ícone de lápis para editar o texto de uma tarefa existente.
* **Excluir Tarefas:** Clique no ícone de lixeira para remover uma tarefa da lista.
* **Marcar Tarefas como Concluídas:** Clique na caixa de seleção ao lado da tarefa para marcá-la como concluída.
* **Modo Claro/Escuro:** Alterne entre os modos claro e escuro clicando no ícone de lua/sol no cabeçalho.
* **Relógio em Tempo Real:** Um relógio digital exibe a hora atual na interface.
* **Persistência de tema:** O tema escolhido é salvo no local storage do navegador.

## Tecnologias Utilizadas

* **HTML:** Estrutura da página web.
* **CSS:** Estilização da interface.
* **JavaScript:** Lógica da aplicação e manipulação do DOM.
* **Font Awesome:** Ícones para os botões de edição e exclusão.

## Estrutura de Arquivos

Todo-App/ 
├── index.html 
├── style.css 
└── script.js

* `index.html`: Arquivo HTML principal do aplicativo.
* `style.css`: Arquivo CSS com a estilização da interface.
* `script.js`: Arquivo JavaScript com a lógica da aplicação.

## Dependências

* **Font Awesome:** Os ícones são carregados via CDN. Certifique-se de ter uma conexão com a internet para que os ícones sejam exibidos corretamente.
